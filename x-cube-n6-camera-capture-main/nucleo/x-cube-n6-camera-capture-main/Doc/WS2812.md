# WS2812 RGB LED Driver

Minimal WS2812 (NeoPixel) driver for STM32N6 using **TIM1 PWM + GPDMA1** to generate the precise timing required by WS2812 LEDs.

## Hardware

| Signal        | Pin   | Function                          |
|---------------|-------|-----------------------------------|
| WS2812 DATA   | PE9   | TIM1_CH2 PWM output               |
| DMA           | GPDMA1_Channel1 | Pushes PWM duty-cycle buffer to TIM1 |

## Quick Start

```c
#include "ws2812.h"

// In main_thread (after TIM1 + DMA init):
MX_GPDMA1_Init();
MX_TIM1_Init();
WS2812_Init();

// Turn LEDs on / off:
WS2812_TurnOn();   // White, default brightness
WS2812_TurnOff();  // All LEDs off

// Set a custom color:
WS2812_SetColor(0xFF0000);  // Red
WS2812_SetColor(0x00FF00);  // Green
WS2812_SetColor(0x0000FF);  // Blue

// Adjust brightness (0-100%):
WS2812_SetBrightness(50);
```

## Configuration

Edit `Inc/ws2812.h` to match your hardware:

| Define                      | Default | Description                        |
|-----------------------------|---------|------------------------------------|
| `WS2812_NUM_LEDS`           | 2       | Number of LEDs in the chain        |
| `WS2812_BRIGHTNESS_DEFAULT` | 10      | Startup brightness (0-100%)        |
| `WS2812_PERIOD`             | 500     | Timer period                       |
| `WS2812_PWM_ONE`            | 80      | PWM duty for logic "1"             |
| `WS2812_PWM_ZERO`           | 30      | PWM duty for logic "0"             |
| `WS2812_RESET_ENTRIES`      | 1700    | Reset gap entries (>50µs silence)  |

## API Reference

| Function                         | Description                              |
|----------------------------------|------------------------------------------|
| `WS2812_Init()`                  | Initialize driver (call after TIM/DMA)   |
| `WS2812_SetColor(uint32_t rgb)`  | Set all LEDs to 0xRRGGBB color           |
| `WS2812_TurnOn()`                | Turn all LEDs on (white)                 |
| `WS2812_TurnOff()`               | Turn all LEDs off                        |
| `WS2812_SetBrightness(uint8_t)`  | Set global brightness 0-100%             |
| `WS2812_GetBrightness()`         | Get current brightness                   |
| `WS2812_Update()`                | Send buffer to LEDs (auto-called)        |

## Timing

The WS2812 protocol requires precise pulse widths:

| Bit  | T0H (Low)  | T1H (High) |
|------|------------|------------|
| ~    | ~400 ns    | ~800 ns    |

Reset code: > 50 µs low period between frames.

The driver generates these timings by pre-computing a PWM duty-cycle buffer and streaming it via DMA to TIM1.

## Notes

- All LEDs in the chain receive the same color (universe broadcast).
- Buffer size = `(WS2812_NUM_LEDS * 24) + WS2812_RESET_ENTRIES` uint16_t entries.
- Increase `WS2812_RESET_ENTRIES` if LEDs show ghosting or dropped frames.
